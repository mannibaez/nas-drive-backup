NAS Drive Backup

A personal backup utility operated by Manuel Báez. It uses rclone to download selected Google Drive files and folders that the operator is authorized to access to privately managed network-attached storage (NAS).

How it works

The operator authorizes Google Drive access through Google sign-in. The backup is configured to read selected folders and periodically copy new or changed files to the NAS. It does not upload changes to Google Drive or delete source files.

The Google read-only permission can cover files accessible to the account; the backup configuration selects which folders are copied. This website is informational and does not provide a sign-in form or access to the backup.

Privacy and contact

Read the privacy policy for data handling, retention, and access controls. This utility is for the operator's personal use and is not a public backup service.
